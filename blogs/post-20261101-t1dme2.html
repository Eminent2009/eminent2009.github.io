Canvas 爱心粒子动画全解析：一个公式，500 个粒子，一次浪漫的绽放

一段零依赖、纯原生 JavaScript 写成的爱心粒子动画：黑色全屏画布上，粉色心形轮廓不断向四周迸发粒子，粒子越飞越慢、渐渐淡去，循环往复。整份代码不到 200 行，却完整覆盖了参数方程、对象池、缓动动画这些经典前端技术。本文拆解它的数学内核与实现细节，你可以直接复制运行，也能照着参数表调出自己的版本。

一、先看效果

动画的表现是这样的：

点此预览界面

  • 页面是一整块黑色背景，正中间有一个粉色心形轮廓；
  • 心形的边缘不断"长出"小粒子，沿着"从心形中心指向该点"的方向向外飞；
  • 粒子一边飞一边减速、一边变透明，最终消散；
  • 旧的粒子消失，新的粒子不断补充，形成"绽放 → 消散 → 绽放"的循环。

视觉上像是心形在持续发光、向外抛洒光尘，适合用作博客的装饰、表白页或者桌面屏保。

二、核心原理：心形是怎么"长"出来的

整个动画的地基是一条数学公式——心形参数方程。代码里的 pointOnHeart(t) 用参数 t（取值范围 −π 到 π）算出心形轮廓上的每一个点：

HTML
x(t) = 160 · sin³(t)
y(t) = 130 · cos(t) − 50 · cos(2t) − 20 · cos(3t) − 10 · cos(4t) + 25

对应代码：

JavaScript
function pointOnHeart(t) {
  return new Point(
    160 * Math.pow(Math.sin(t), 3),
    130 * Math.cos(t) - 50 * Math.cos(2 * t) - 20 * Math.cos(3 * t) - 10 * Math.cos(4 * t) + 25
  );
}

sin³(t) 负责让左右两瓣对称鼓起，那一串 cos 项则负责修出心尖和上沿的弧度。

这条公式在代码里被用了两次：

  1. 生成粒子贴图：先用一个离屏 canvas，把 t 从 −π 到 π 按 0.01 步长描出心形路径，填充粉色 #ea80b0，再把画布转成图片（toDataURL），作为每个粒子的"样子"；
  2. 生成发射点：动画运行时，每帧从轮廓上随机取点（Math.PI - 2 * Math.PI * Math.random()），在该点位置发射新粒子。

小知识：动画里那颗"心"其实不是画出来的——它是用公式算出来的。把公式里的系数改一改，心形就会变胖、变瘦、变歪，这是最好玩的地方。

四、粒子系统的三个关键设计

1. 环形队列对象池：不用 new 也能有 500 个粒子

如果每帧都 new Particle()，浏览器会不断分配内存、触发垃圾回收，动画很容易卡顿。这段代码用了对象池 + 环形队列：

  • 初始化时一次性创建 500 个粒子对象，存进数组；
  • 用两个指针管理：firstActive（最老的活跃粒子）和 firstFree（下一个空位）；
  • 新粒子"复活"到 firstFree 指向的空位上，两个指针都做循环取模，像钟表一样转圈；
  • 当某个粒子 age >= duration 时，它不再被绘制，下一个新粒子会直接覆盖它的位置——对象被反复"复用"，全程零垃圾。
代码

2. 物理模型：速度 + 负加速度，造出"绽放"感

每个粒子只有三样状态：位置、速度、加速度。每帧更新：

JavaScript
position += velocity * dt;   // 移动
velocity += acceleration * dt; // 变速

关键在初始化时这一句：

JavaScript
this.acceleration.x = dx * settings.particles.effect;  // effect = -0.75
this.acceleration.y = dy * settings.particles.effect;

加速度 = 初速度 × (−0.75)，也就是和运动方向相反。粒子刚出生时冲得最快，随后被"负加速度"持续刹车，越飞越慢。配合透明度渐隐，就有了"绽放后缓缓消散"的呼吸感。

如果把 effect 调成正值，粒子会越飞越快、冲出屏幕；调成 −1 左右，粒子几乎飞不动，心形会显得更"凝聚"。

3. 缓动 + 渐隐：粒子的"生命曲线"

粒子在 duration（默认 2 秒）内走完一生，两个视觉参数随年龄变化：

JavaScript
function ease(t) { return (--t) * t * t + 1; }

var size = image.width * ease(this.age / settings.particles.duration);
context.globalAlpha = 1 - this.age / settings.particles.duration;
  • 尺寸：经过缓动函数微调，粒子在生命周期中先略缩后复原，避免机械的匀速缩放；
  • 透明度：从 1 线性降到 0，粒子"淡入又淡出"，和黑色的背景融合得干净。

五、动画主循环：每一帧发生了什么

requestAnimationFrame 驱动整个循环，让动画跟随屏幕刷新率（通常 60 帧/秒）运行：

MERMAID
flowchart TD
    A["requestAnimationFrame(render)"] --> B["计算 deltaTime<br/>（距上一帧的秒数）"]
    B --> C["按 粒子速率 × deltaTime<br/>生成若干新粒子"]
    C --> D["在心形轮廓随机取点<br/>沿径向赋初速度"]
    D --> E["粒子池 add：<br/>复用环形队列空位"]
    E --> F["update：位移积分<br/>负加速度减速"]
    F --> G["draw：按年龄<br/>缓动缩放 + 透明度渐隐"]
    G --> H["回收年龄 ≥ duration<br/>的粒子，腾出空位"]
    H --> A

配套的完整逻辑：

JavaScript
function render() {
  requestAnimationFrame(render);              // 下一帧
  var newTime = new Date().getTime() / 1000,
      deltaTime = newTime - (time || newTime);
  time = newTime;

  context.clearRect(0, 0, canvas.width, canvas.height);  // 清屏

  var amount = particleRate * deltaTime;      // 本帧要发射的粒子数
  for (var i = 0; i < amount; i++) {
    var pos = pointOnHeart(Math.PI - 2 * Math.PI * Math.random()); // 轮廓随机点
    var dir = pos.clone().length(settings.particles.velocity);     // 径向初速
    particles.add(canvas.width / 2 + pos.x, canvas.height / 2 - pos.y, dir.x, -dir.y);
  }

  particles.update(deltaTime);   // 更新所有活跃粒子
  particles.draw(context, image); // 绘制所有活跃粒子
}

几个值得注意的细节：

  • particleRate = 粒子数 / 寿命 = 500 / 2 = 250，即每秒钟发射 250 个粒子，配合 2 秒寿命，屏幕上始终约 500 个粒子在飞，不多不少；
  • 发射点的坐标做了居中处理（canvas.width / 2 + pos.x），所以心形永远在画布正中间；
  • 粒子初速度的方向取自轮廓点本身的方向（pos.clone().length(velocity)），也就是"从心形中心指向该点"的方向，天然向外。

六、可调参数速查表

所有效果参数都集中在 settings.particles 里，改这里就够了：

参数默认值作用怎么调
length500粒子池容量 = 同时存在的粒子数上限调大更密集绚丽，低配设备调小（如 200）更流畅
duration2单个粒子存活秒数调大拖尾更长、更"绵延"；调小更干脆
velocity100粒子初速度（像素/秒）调大绽放更炸裂，调小更轻柔
effect-0.75加速度系数，负值=减速越接近 0 飞得越远；越接近 −1 越早停下
size30粒子贴图边长（像素）调大粒子更粗壮，调小更细腻如星光

换颜色：改粒子贴图的填充色 context.fillStyle = '#ea80b0'，想换什么色就换什么色（比如纯白变"雪花心"，金色变"流光心"）。

/*
 * Settings
 */
var settings = {
  particles: {
    length:   500, // maximum amount of particles
    duration:   2, // particle duration in sec
    velocity: 100, // particle velocity in pixels/sec
    effect: -0.75, // play with this for a nice effect
    size:      30, // particle size in pixels
  },
};

/*
 * RequestAnimationFrame polyfill by Erik Möller
 */
(function(){
  var b = 0;
  var c = ["ms", "moz", "webkit", "o"];
  for (var a = 0; a < c.length && !window.requestAnimationFrame; ++a) {
    window.requestAnimationFrame = window[c[a] + "RequestAnimationFrame"];
    window.cancelAnimationFrame = window[c[a] + "CancelAnimationFrame"] ||
      window[c[a] + "CancelRequestAnimationFrame"];
  }
  if (!window.requestAnimationFrame) {
    window.requestAnimationFrame = function(h) {
      var d = new Date().getTime();
      var f = Math.max(0, 16 - (d - b));
      var g = window.setTimeout(function(){ h(d + f); }, f);
      b = d + f;
      return g;
    };
  }
  if (!window.cancelAnimationFrame) {
    window.cancelAnimationFrame = function(d){ clearTimeout(d); };
  }
}());

/*
 * Point class
 */
var Point = (function() {
  function Point(x, y) {
    this.x = (typeof x !== 'undefined') ? x : 0;
    this.y = (typeof y !== 'undefined') ? y : 0;
  }
  Point.prototype.clone = function() {
    return new Point(this.x, this.y);
  };
  Point.prototype.length = function(length) {
    if (typeof length == 'undefined')
      return Math.sqrt(this.x * this.x + this.y * this.y);
    this.normalize();
    this.x *= length;
    this.y *= length;
    return this;
  };
  Point.prototype.normalize = function() {
    var length = this.length();
    this.x /= length;
    this.y /= length;
    return this;
  };
  return Point;
})();

/*
 * Particle class
 */
var Particle = (function() {
  function Particle() {
    this.position = new Point();
    this.velocity = new Point();
    this.acceleration = new Point();
    this.age = 0;
  }
  Particle.prototype.initialize = function(x, y, dx, dy) {
    this.position.x = x;
    this.position.y = y;
    this.velocity.x = dx;
    this.velocity.y = dy;
    this.acceleration.x = dx * settings.particles.effect;
    this.acceleration.y = dy * settings.particles.effect;
    this.age = 0;
  };
  Particle.prototype.update = function(deltaTime) {
    this.position.x += this.velocity.x * deltaTime;
    this.position.y += this.velocity.y * deltaTime;
    this.velocity.x += this.acceleration.x * deltaTime;
    this.velocity.y += this.acceleration.y * deltaTime;
    this.age += deltaTime;
  };
  Particle.prototype.draw = function(context, image) {
    function ease(t) {
      return (--t) * t * t + 1;
    }
    var size = image.width * ease(this.age / settings.particles.duration);
    context.globalAlpha = 1 - this.age / settings.particles.duration;
    context.drawImage(image, this.position.x - size / 2,
      this.position.y - size / 2, size, size);
  };
  return Particle;
})();

/*
 * ParticlePool class
 */
var ParticlePool = (function() {
  var particles,
      firstActive = 0,
      firstFree = 0,
      duration = settings.particles.duration;

  function ParticlePool(length) {
    particles = new Array(length);
    for (var i = 0; i < particles.length; i++)
      particles[i] = new Particle();
  }
  ParticlePool.prototype.add = function(x, y, dx, dy) {
    particles[firstFree].initialize(x, y, dx, dy);
    firstFree++;
    if (firstFree == particles.length) firstFree = 0;
    if (firstActive == firstFree) firstActive++;
    if (firstActive == particles.length) firstActive = 0;
  };
  ParticlePool.prototype.update = function(deltaTime) {
    var i;
    if (firstActive < firstFree) {
      for (i = firstActive; i < firstFree; i++)
        particles[i].update(deltaTime);
    }
    if (firstFree < firstActive) {
      for (i = firstActive; i < particles.length; i++)
        particles[i].update(deltaTime);
      for (i = 0; i < firstFree; i++)
        particles[i].update(deltaTime);
    }
    while (particles[firstActive].age >= duration && firstActive != firstFree) {
      firstActive++;
      if (firstActive == particles.length) firstActive = 0;
    }
  };
  ParticlePool.prototype.draw = function(context, image) {
    var i;
    if (firstActive < firstFree) {
      for (i = firstActive; i < firstFree; i++)
        particles[i].draw(context, image);
    }
    if (firstFree < firstActive) {
      for (i = firstActive; i < particles.length; i++)
        particles[i].draw(context, image);
      for (i = 0; i < firstFree; i++)
        particles[i].draw(context, image);
    }
  };
  return ParticlePool;
})();

/*
 * Putting it all together
 */
(function(canvas) {
  var context = canvas.getContext('2d'),
      particles = new ParticlePool(settings.particles.length),
      particleRate = settings.particles.length / settings.particles.duration,
      time;

  function pointOnHeart(t) {
    return new Point(
      160 * Math.pow(Math.sin(t), 3),
      130 * Math.cos(t) - 50 * Math.cos(2 * t) -
        20 * Math.cos(3 * t) - 10 * Math.cos(4 * t) + 25
    );
  }

  var image = (function() {
    var canvas = document.createElement('canvas'),
        context = canvas.getContext('2d');
    canvas.width = settings.particles.size;
    canvas.height = settings.particles.size;

    function to(t) {
      var point = pointOnHeart(t);
      point.x = settings.particles.size / 2 + point.x * settings.particles.size / 350;
      point.y = settings.particles.size / 2 - point.y * settings.particles.size / 350;
      return point;
    }

    context.beginPath();
    var t = -Math.PI;
    var point = to(t);
    context.moveTo(point.x, point.y);
    while (t < Math.PI) {
      t += 0.01;
      point = to(t);
      context.lineTo(point.x, point.y);
    }
    context.closePath();
    context.fillStyle = '#ea80b0';
    context.fill();

    var image = new Image();
    image.src = canvas.toDataURL();
    return image;
  })();

  function render() {
    requestAnimationFrame(render);
    var newTime = new Date().getTime() / 1000,
        deltaTime = newTime - (time || newTime);
    time = newTime;

    context.clearRect(0, 0, canvas.width, canvas.height);

    var amount = particleRate * deltaTime;
    for (var i = 0; i < amount; i++) {
      var pos = pointOnHeart(Math.PI - 2 * Math.PI * Math.random());
      var dir = pos.clone().length(settings.particles.velocity);
      particles.add(canvas.width / 2 + pos.x, canvas.height / 2 - pos.y,
        dir.x, -dir.y);
    }

    particles.update(deltaTime);
    particles.draw(context, image);
  }

  function onResize() {
    canvas.width = canvas.clientWidth;
    canvas.height = canvas.clientHeight;
  }

  window.onresize = onResize;

  setTimeout(function() {
    onResize();
    render();
  }, 10);
})(document.getElementById('pinkboard'));
</script>
</BODY>
</HTML>

九、改造灵感

照着这套结构，可以很快改出自己的版本：

  1. 让心形"坍缩"：把 effect 从负值改成正数，粒子会加速飞向远处然后消失，视觉变成"炸开"；
  2. 换图形：把 pointOnHeart 换成其他参数方程（比如星形线、蝴蝶曲线），粒子贴图和发射点会同步变成新图形；
  3. 加交互：监听鼠标位置，让心形跟随鼠标移动，或在点击处额外喷发一簇粒子；
  4. 多色渐变：按粒子年龄切换颜色，让淡出过程更梦幻；
  5. 改文字心：用 fillText 在心形路径内写上名字，就成了独一无二的表白页。

结语

这段代码最迷人的地方在于：浪漫的视觉效果，背后只是一条参数方程、一个对象池和一个 requestAnimationFrame 循环。三个经典的前端知识点，合成了一段两秒一次的"绽放"。
